# Работа с uk-flowers

Это учебный ML-проект и техническая проверка процесса GitHub → SourceCraft → GitHub.

## Подготовка и проверки

- Python 3.13, uv 0.13.1. Зависимости фиксирует `uv.lock`.
- Подготовка и все проверки: `bash scripts/pilot-check.sh all`.
- Только автономные интеграционные проверки: `bash scripts/pilot-check.sh smoke`.
- Проверки исходного проекта: `bash scripts/pilot-check.sh quality`.
- Результаты и журналы находятся в `reports/pilot/`; каталог не коммитится.
- Не запускай обучение, `dvc pull`, скачивание pretrained-весов или обращения к MLflow/S3 для обычных тестов. Используй временные файлы, CPU и `pretrained=False`.

## Работа над задачей

- Сначала воспроизведи проблему; затем внеси минимальную правку и проверь результат.
- Меняй только необходимое для поручения. Не исправляй соседние ошибки без основания.
- Не отключай проверки, не снижай порог покрытия 80%, не добавляй `skip`, `xfail`, `nosec` или подавление типов ради зелёного CI.
- Известные исходные ошибки перечислены в `pilot/baseline.md`. Отделяй их от новых регрессий.
- Результат оформляй отдельной веткой и предложением изменений. Укажи выполненные команды, результат и оставшиеся ограничения.
- Не коммить секреты, реальные пользовательские данные, веса модели, датасеты, `.venv` и журналы.
- Переносы между хостингами выполняет оператор с узла обмена. Не делай force-push и не сливай свою работу самостоятельно.
