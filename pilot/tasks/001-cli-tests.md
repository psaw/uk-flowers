# Первая задача AI-коллеге: актуализировать тест CLI

## Проблема

`tests/test_scripts.py::test_main` вызывает `scripts.main(argv)` и ожидает код возврата 0. Текущий `main()` не принимает аргументов и передаёт управление Fire. Исходный тест и проверка mypy падают.

## Задание

Изучи фактический контракт CLI. Замени устаревший тест содержательными проверками диспетчеризации команд `train` и `infer`, передачи Hydra overrides и обработки отсутствующего пути изображения. Используй моки для обучения и тяжёлых вычислений. Сохрани действующее поведение приложения, если не обнаружишь отдельную доказанную ошибку.

## Приёмка

- Новые тесты проверяют наблюдаемое поведение, а не только вызовы реализации.
- Тесты не скачивают данные/веса, не вызывают DVC и не требуют MLflow или GPU.
- `bash scripts/pilot-check.sh smoke` проходит.
- `uv run --no-sync pytest tests/test_scripts.py` проходит.
- `uv run --no-sync mypy src tests` проходит.
- `ruff check --no-fix src tests` и `ruff format --check src tests` проходят.
- Остаточные замечания Bandit и фактическое покрытие явно перечислены; проверки не ослаблены.
- Работа оформлена отдельной веткой и предложением изменений с результатами команд.
